# Rust version operations

Issue #15, T2. Rust reads the same Gradle and Xcode fixtures, follows Xcode
configuration lists, and derives byte-range replacements. It preflights all
plans before staging replacements next to their destinations. A failed write
or verification restores completed replacements in reverse order. A concurrent
edit prevents rollback from overwriting unrecognized content.

The native test host uses filesystem calls in the temporary directory. Tests
also inject rename, verification and restore failures. Cargo tests run before
the existing Node characterization suite. Node integration will use the same
Rust crate compiled to WebAssembly, with OS operations supplied by Node.
